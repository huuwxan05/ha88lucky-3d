# HA88Lucky 3D assets

This folder is intentionally free of third-party copyrighted game assets.
Put only assets you own or have a license to use here.

Recommended formats:
- `.glb` / `.gltf` for 3D models
- `.webp` / `.png` for textures
- `.mp3` / `.ogg` for audio

The current `public/game3d/index.html` is a Three.js prototype and can be extended to load licensed GLB characters/environments.
